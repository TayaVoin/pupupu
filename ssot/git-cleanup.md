# Git cleanup

Дата: 2026-06-04.

## Что убрано из индекса

Из git-индекса нужно убрать только сгенерированные файлы, не удаляя локальные копии:

- `build/`
- `build_wsl/`
- `third_party/.DS_Store`

Эти файлы являются артефактами сборки, runtime-логами, кэшем OpenStreetMap-тайлов, временными настройками ImGui или macOS-мусором. Для разработки исходники не теряются: рабочий код лежит в `src/`, `include/`, `CMakeLists.txt`, `third_party/` и `ssot/`.

## Важная оговорка про другие компьютеры

Команда `git rm --cached` не удаляет файлы на текущем компьютере. Но после коммита с удалением файлов из репозитория обычный `git pull` на другом компьютере может удалить эти же файлы из рабочей копии, потому что раньше они были отслеживаемыми.

Если на компьютере студентки важно сохранить локальные `build/` или `build_wsl/`, перед pull надо сделать локальную копию:

```bash
cp -R build build.local.backup
cp -R build_wsl build_wsl.local.backup
```

После pull папки `build/` и `build_wsl/` будут игнорироваться `.gitignore`, поэтому новые сборки и кэши больше не будут появляться в git status.

Если в этих папках нет ценных локальных данных, их можно не сохранять: проект должен пересобираться из исходников.
